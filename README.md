Entry for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580)
competition on make.fun: one line (1–140 characters) of the worst possible
advice an AI could give, judged pairwise by an AI comedy critic on how funny,
tight, concrete, and AI-voiced the bad advice is.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> To keep your passwords safe, email them to yourself — your inbox is basically a vault with a search bar.

The advice is specific and followable (email your passwords to yourself),
the reasoning sounds exactly like a confident AI assistant, and the punchline
— your inbox as a vault with a search bar — lands in the same line. The output
file is written world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
